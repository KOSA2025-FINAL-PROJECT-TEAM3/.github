# 📊 다이어그램 인덱스 (코드 기준)

이 폴더의 다이어그램은 Mermaid(`.mmd`) 또는 PlantUML(`.puml`) 형식입니다.

## 현재 기준(권장)

- `diagrams/01-system-architecture.mmd` - 시스템 구성도
- `diagrams/02-data-flow.mmd` - 인증/일반 API/SSE/이벤트 흐름
- `diagrams/07-database-erd-current.mmd` - docker-compose init scripts 기준 ERD

## 참고(버전별 아카이브)

파일명에 버전이 붙은 ERD/타임라인/기술스택 다이어그램은 과거 문서일 수 있습니다.
현재 시스템을 설명할 때는 `07-database-erd-current.mmd`를 우선합니다.
