# 보안 및 문서 작성 가이드라인

## 개요

이 저장소는 공개 문서를 포함할 수 있으므로, 문서 작성 시 보안을 최우선으로 고려합니다.

## 보안 주의사항

### 민감 정보 보호

다음과 같은 민감 정보는 **절대 포함하지 않습니다**:

- API 키 및 인증 토큰
- 데이터베이스 접속 정보(실제 계정/비밀번호/호스트)
- 내부 네트워크 구조나 사설 IP
- 운영 환경의 비공개 엔드포인트

> **포트 번호 자체는 로컬 개발 문맥에서 허용**됩니다.
> 단, **실제 운영 주소 + 포트** 조합은 노출하지 않습니다.

### 정보 마스킹 방법

민감 정보를 예시로 사용해야 할 경우, 다음과 같이 마스킹합니다:

```
# ❌ 잘못된 예시
서버 주소: 192.168.1.100:8080
DB 접속: postgresql://user:password@10.0.0.5:5432/dbname

# ✅ 올바른 예시
서버 주소: <SERVER_HOST>:<PORT>
DB 접속: postgresql://<USERNAME>:<PASSWORD>@<DB_HOST>:<DB_PORT>/<DB_NAME>
```

## 문서 작성 기준

### KISA Secure Coding 가이드라인 준수

모든 README 및 문서 작성 시 다음을 준수합니다:

1. **입력 데이터 검증 및 표현**
   - 코드 예제에서 사용자 입력값 검증 로직 포함
2. **보안 기능**
   - 인증/인가 예제는 보안 모범 사례 기반으로 작성
3. **에러 처리**
   - 에러 메시지에 시스템 내부 정보 노출 금지
4. **코드 품질**
   - 안전한 코딩 패턴 사용
