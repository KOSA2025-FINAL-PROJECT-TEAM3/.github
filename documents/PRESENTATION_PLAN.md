# 🎤 발표용 PPT 구성안 (40~50페이지) + 시연 시나리오

이 문서는 **현재 구현 기준**으로 발표용 PPT의 구조, 순서, 필요한 자료와 시연 흐름을 정리합니다.
목표 페이지 수는 **45장 고정**이며, 발표 시간은 **30분 내외**를 기준으로 구성합니다.

---

## 0) 전제 및 업데이트 요약

- 발표 관점: PM 기획자 시선(문제-가치-사용자-성과-리스크 순서 강화)
- 슬라이드 수: 45장 고정
- 시연: 5~7분 데모 + 30분 전체 발표 흐름에 맞춘 타임라인
- 다이어그램 소스: `.github/diagrams` 우선 사용

---

## 1) 발표 목표 및 메시지

- **문제 정의**: 독거 시니어 복약 관리의 사각지대
- **해결 전략**: 가족 돌봄 네트워크 + 실시간 모니터링
- **차별성**: 약-음식 경고, OCR 자동 등록, SSE 실시간 알림
- **구현 상태**: Gateway/Auth/Core + Docker Compose + GitOps(K8s) 기반

## 4) 시연 시나리오 (5~7분)

### 4.1 시연 전 준비

- 로컬 또는 데모 서버에서 **Gateway/Auth/Core** 기동
- SSE 알림/채팅 기능 활성화 확인
- 테스트 계정 2개 준비(시니어/보호자)
- 복약 스케줄 1개, OCR 대상 이미지 1개 준비

### 4.2 데모 스토리라인

1. **보호자 로그인**
2. **가족 네트워크 연결** (초대 승인 또는 이미 연결된 상태)
3. **복약 스케줄 등록**
4. **시니어 앱에서 복약 확인**
5. **보호자 앱에서 실시간 알림 수신**
6. **OCR로 처방전 등록**
7. **약-음식 경고 표시**
8. **가족 채팅으로 확인 메시지 전송**

### 4.3 시연 단계별 화면/포인트

| 단계 | 화면 | 포인트 | 성공 기준 |
|---:|---|---|---|
| 1 | 로그인 | Auth + JWT | 토큰 발급 완료 |
| 2 | 가족 연결 | 초대/승인 | 가족 그룹 생성 |
| 3 | 스케줄 등록 | 복약 시간 | 일정 생성 |
| 4 | 복약 확인 | 시니어 체크 | 기록 저장 |
| 5 | 알림 수신 | SSE | 보호자 알림 도착 |
| 6 | OCR 등록 | 이미지 업로드 | 약 정보 추출 |
| 7 | 경고 표시 | 약-음식 룰 | 경고 노출 |
| 8 | 채팅 | 실시간 메시지 | 전달 확인 |

### 4.4 실패 대비 플랜

- SSE 불안정 시: “알림 히스토리” 화면으로 대체 설명
- OCR 실패 시: 수동 입력 화면으로 전환
- 네트워크 지연 시: 캡처 영상 20~30초 준비

## 7) PM 관점 보강 포인트

- **가치 제안**: 가족 돌봄 네트워크 + 실시간 모니터링이 만드는 차별성
- **핵심 지표**: 복약 순응도, 알림 도달률, OCR 성공률
- **범위 관리**: MVP(가족/복약/알림) vs 확장(OCR/Voice/리포트)
- **리스크**: OCR 품질, SSE 연결 안정성, 데이터 정확도
- **대응 전략**: 폴백 UI, 알림 히스토리, 데이터 검증 로그
